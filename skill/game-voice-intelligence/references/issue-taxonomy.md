# Bilingual feedback issue taxonomy

Apply one primary topic per review using the most specific matching evidence.

| Topic | Typical signals |
| --- | --- |
| Performance | crash, lag, FPS, loading; 崩溃、闪退、卡顿、掉帧、发热、优化 |
| Monetization | price, pity, gacha, paywall; 价格、氪金、抽卡、保底、礼包 |
| Fashion/Customization | outfit, wardrobe, dye; 时装、换装、穿搭、染色、捏脸 |
| Combat/Balance | combat, weapon, balance; 战斗、武器、伤害、平衡、强度 |
| Story/Character | plot, dialogue, voice acting, romance; 剧情、角色设计、文案、配音、好感 |
| Content/Progression | quest, event, exploration, grind; 任务、活动、探索、长草、养成 |
| UI/UX | interface, inventory, camera, tutorial; 界面、背包、镜头、操作、引导 |
| Social/Community | guild, co-op, chat, server; 公会、联机、组队、聊天、服务器 |
| Account/Service | login, account deletion, transfer, support; 登录、账号、迁移、客服、封号 |
| Other | no reliable match |

Do not infer sentiment from topic alone. Recommendation status and star rating are evidence, but irony and mixed feedback may require human review.
