# Voice-of-Player questions

GamePulse is built to answer practical research and product questions from a game name:

1. Which storefront, social, and community sources were actually collected?
2. Which requested sources were unavailable, and was the cause credentials, permissions, or no matching content?
3. What issues dominate each platform separately?
4. Which issues converge across multiple source types?
5. Which topics are disproportionately negative within their source-native or declared sentiment method?
6. Which topics are gaining share in the recent window?
7. Are high-volume complaints driven by one platform, one viral item, or several independent communities?
8. Which original comments best support or contradict each proposed theme?
9. Where is the taxonomy failing, as indicated by a high `Other` share?
10. Which findings need first-party telemetry or an experiment before product impact can be claimed?

The intended output is a traceable investigation queue, not a universal player-satisfaction score.
