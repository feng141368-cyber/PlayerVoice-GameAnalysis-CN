# Resume copy

## Project title

**GamePulse — Cross-Platform Game Voice Intelligence Agent Skill**

## Three-bullet version

- Built a name-first Agent Skill and Python ETL pipeline that discovers game aliases and collects real player feedback across Steam, Bilibili, Reddit, YouTube, approved Weibo/Xiaohongshu/Douyin providers, and authorized community exports.
- Designed a unified, privacy-minimized schema with raw source snapshots, incremental ID-based deduplication, collection manifests, multilingual topic classification, trend windows, and source-linked evidence reporting.
- Produced and validated a live *Tower of Fantasy* case using 327 public Steam and Bilibili records, while explicitly separating unavailable platforms, sentiment proxies, sampling bias, and public discussion from first-party behavioural impact.

## One-line version

Developed a Python Agent Skill that turns a game name into a traceable multi-platform Voice-of-Player report through API collection, multilingual normalization, incremental ETL, and evidence-linked issue prioritization.

## Keywords

Python, REST APIs, OAuth, pandas, ETL, data normalization, multilingual text analysis, social listening, game product research, Agent Skills, Git, CI.
